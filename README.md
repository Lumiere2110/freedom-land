# Freedom Land

みんなで遊べるオリジナル3Dミニゲーム集です。ゲームエンジン [Godot](https://godotengine.org/) 4.7 で作っています。
オンラインで最大8人まで一緒に遊べて、人数が足りないときはCPUが入ります。

## 遊べるゲーム

| ゲーム | 種類 | ルール |
|---|---|---|
| コインラッシュ | 対戦 | 60秒でコインを一番多く集めた人の勝ち。金の大コインは5枚ぶん。ダッシュでぶつかると相手のコインを2枚落とさせる |
| ぶつかりリング | 対戦 | ダッシュで相手をリングの外へ押し出す。リングはだんだん小さくなる。最後まで残った人の勝ち |
| ぬけおちパネル | 対戦 | 乗ったパネルはふるえてから落ちる。2段あるパネルの下まで落ちたら脱落 |
| 浮島クリスタル | 協力 | みんなでクリスタルを集める。トゲ玉に当たったり島から落ちたりすると1個へる |

起動すると「広場」に出ます。広場のまわりにある光る門(ポータル)にホストが入ると、そのゲームが全員で始まります。

## 操作

| 操作 | キーボード | コントローラー |
|---|---|---|
| 移動 | WASD / 矢印キー | 左スティック |

## ダウンロード

**[最新版をダウンロード(Releases)](https://github.com/Lumiere2110/freedom-land/releases/latest)** から `FreedomLand.exe` をダウンロードして、ダブルクリックすると遊べます(インストール不要)。
Windows に「PC を保護しました」と出たときは、「詳細情報」→「実行」を押してください。

## 遊び方(ソースコードから動かす)

1. [Godot 4.7](https://godotengine.org/download/) を起動して「インポート」からこのフォルダの `project.godot` を開く
2. 右上の ▶(F5)を押すと始まる

### exe(Windows アプリ)を作る

Godot の書き出し用テンプレート(4.7.2)を入れてから、次を実行すると `export/FreedomLand.exe` ができます。
exe ファイル1つでゲームが全部入っているので、友達にもこのファイルを渡せば一緒に遊べます。

```bash
godot --headless --path . --export-release "Windows Desktop" export/FreedomLand.exe
```

Godot エディタからなら「プロジェクト → エクスポート → Windows Desktop → プロジェクトのエクスポート」でも作れます。

### オンラインで遊ぶ

- **部屋を作る人(ホスト):** タイトル画面で「部屋を作る」を押します。広場の左上に出る **IPアドレス** をみんなに教えます。
- **部屋に入る人:** ホストのIPアドレスを入力して「部屋に入る」を押します。
- 同じWi-Fi(同じ家のネットワーク)なら、そのままつながります。
- 離れた場所の人と遊ぶときは、ホストのルーターで **UDPポート 24680** を開ける(ポート開放)か、Tailscale のような「仮想の同じネットワーク」を作るアプリを使ってください。
- Windows のファイアウォールの確認が出たら「許可」を選んでください。

## ファイルの説明(はじめての人向け)

```
freedom-land/
├─ project.godot        … プロジェクトの設定(名前・画面の大きさなど)
├─ scenes/main.tscn     … 最初に開く画面。main.gd がついているだけ
└─ scripts/
   ├─ main.gd           … 司令塔。タイトル画面、操作の登録、画面の切りかえ
   ├─ net.gd            … ネットワーク係。部屋を作る・入る・プレイヤー一覧
   ├─ build.gd          … ものづくり係。床・木・文字などを作る便利な関数
   ├─ player.gd         … キャラクター。歩く・ジャンプ・ダッシュ・通信
   ├─ base_game.gd      … すべてのゲームの土台。カメラ・時間・点数・結果発表
   ├─ hub.gd            … 広場
   └─ games/
      ├─ coin_rush.gd       … コインラッシュ
      ├─ bump_ring.gd       … ぶつかりリング
      ├─ panel_drop.gd      … ぬけおちパネル
      └─ crystal_island.gd  … 浮島クリスタル
```

どのファイルにも、何をしているかを日本語のメモ(`#` や `##` で始まる行)で書いています。
3Dの見た目は画像やモデルのファイルを使わず、四角・円柱・球などの形を組み合わせてプログラムで作っています。

### 新しいゲームを足すには

1. `scripts/games/` に新しいファイルを作り、1行目を `extends "res://scripts/base_game.gd"` にする
2. `build_world()`(ステージ)、`spawn_point()`(スタート位置)、`game_process()`(毎フレームの処理)を書く
3. `main.gd` の `SCENES` と `GAMES` に1行ずつ足す(広場にポータルが自動で増えます)

## 開発用のテスト

```bash
godot --headless --path . -- --autotest
```

すべての画面を順番に開いて、エラーが出ないか確かめます。`--autohost` と `--autojoin` を2つ同時に起動すると、通信のテストもできます。
