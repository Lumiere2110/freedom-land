# Freedom Land

みんなで遊べるオリジナル3Dミニゲーム集です。ゲームエンジン [Godot](https://godotengine.org/) 4.7 で作っています。
オンラインで最大8人まで一緒に遊べて、人数が足りないときはCPUが入ります。

## 遊べるゲーム

| ゲーム | 種類 | ルール |
|---|---|---|
| コインラッシュ | 対戦 | 60秒でコインを一番多く集めた人の勝ち。金の大コインは5枚ぶん。ダッシュでぶつかると相手のコインを2枚落とさせる |
| ぶつかりリング | 対戦 | ダッシュで相手をリングの外へ押し出す。リングはだんだん小さくなる。最後まで残った人の勝ち |
| ぬけおちパネル | 対戦 | 乗ったパネルはふるえてから落ちる。2段あるパネルの下まで落ちたら脱落 |
| ぐるぐるバー | 対戦 | 台の真ん中から回ってくるバーを、ジャンプでとびこえる。当たると飛ばされる。バーはだんだん速くなり、25秒で2本に増える |
| Bond | チーム 5対5 | 青と赤のチームに分かれ、上・中央・下の3つのレーンで戦う。上と下に2人ずつ、中央にエース(王冠つき・体力と攻撃が強い)。こうげきで近くの敵に光の玉を飛ばし、たおすとチームに1点(エースは2点)。たおされると5秒後に基地から復活。自分の基地では体力回復、敵の基地では体力がへる。150秒で点数が多いチームの勝ち |

## タイトル画面

- **プレイ:** タイトルの後ろで回っている空島(広場)に行きます。まわりにある光る門(ポータル)に入ると、そのゲームがひとり(+CPU)で始まります。終わると空島に戻ります。
- **オンライン:** 「ルームを作成」か「ルームに参加」を選びます。
  - **ルームを作成:** 画面に6文字の **パスワード** が出て、空島に行きます。パスワードをみんなに教えてください。ホストがポータルに入ると、そのゲームが全員で始まります。
  - **ルームに参加:** パスワードを入れて「ルームに入る」を押すと、ホストと同じ空島に行きます。
  - パソコン版とブラウザ版(スマホ)が同じルームで一緒に遊べます。
- **CPUのつよさ:** 空島の左上で「よわい・ふつう・つよい」を選べます(オンラインではホストが選びます)。
- **ポーズ:** ゲーム中に Esc / P(コントローラーはスタート、スマホは画面上の「II」)で止まります。「つづける」「はじめからやりなおす」「空島にもどる」「タイトルにもどる」を選べます。オンライン中はみんなのゲームは止まりません(メニューだけ出ます)。

## 操作

| 操作 | キーボード | コントローラー |
|---|---|---|
| 移動 | WASD / 矢印キー | 左スティック |
| ジャンプ | Space | A |
| ダッシュ(体当たり) | Shift / K | X |
| カメラを回す | Q / E | LB / RB |
| ポーズ | Esc / P | スタート |
| こうげき(Bond) | J / F | B |

スマホ(ブラウザ版)では、画面の左側をさわって動かすと移動、右側をなぞるとカメラ、右下の「ジャンプ」「ダッシュ」ボタン(Bond では「こうげき」ボタンも出ます)、上の「II」でポーズです。スマホは横向きにして遊んでください。

## スマホ・ブラウザで遊ぶ

**[ブラウザ版で遊ぶ](https://lumiere2110.github.io/freedom-land/)**(iPhone・Android・パソコンのブラウザで動きます。オンライン対戦もできます)

- **アプリとして入れる(iPhone):** Safari でブラウザ版を開き、共有ボタン →「ホーム画面に追加」。ホーム画面のアイコンから、アプリのように全画面で開けます。一度開けばオフラインでも遊べます。
- **Android:** Chrome のメニュー →「アプリをインストール」(または「ホーム画面に追加」)。

## ダウンロード(パソコン版)

**[最新版をダウンロード(Releases)](https://github.com/Lumiere2110/freedom-land/releases/latest)** から `FreedomLand-win64.zip` をダウンロードして展開し、中の `FreedomLand.exe` をダブルクリックすると遊べます(インストール不要)。
いっしょに入っている `libwebrtc_native…dll` はオンライン対戦に使うので、exe と同じフォルダに置いたままにしてください。
Windows に「PC を保護しました」と出たときは、「詳細情報」→「実行」を押してください。

## 遊び方(ソースコードから動かす)

1. [Godot 4.7](https://godotengine.org/download/) を起動して「インポート」からこのフォルダの `project.godot` を開く
2. 右上の ▶(F5)を押すと始まる

### exe(Windows アプリ)を作る

Godot の書き出し用テンプレート(4.7.2)を入れてから、次を実行すると `export/FreedomLand.exe` と、オンライン用の WebRTC の dll ができます。
友達に渡すときは、この2つを一緒に渡してください。

```bash
godot --headless --path . --export-release "Windows Desktop" export/FreedomLand.exe
```

Godot エディタからなら「プロジェクト → エクスポート → Windows Desktop → プロジェクトのエクスポート」でも作れます。

### ブラウザ版を作る

Web 用のテンプレートを入れてから、次を実行すると `docs/` にブラウザ版ができます。GitHub Pages(main ブランチの `docs` フォルダ)でそのまま公開しています。

```bash
godot --headless --path . --export-release "Web" docs/index.html
```

- GitHub Pages では特別な設定(COOP/COEP)ができないので、スレッドを使わない版(nothreads)で書き出しています。
- ブラウザ版は軽い描き方(Compatibility)で動くので、霧や光のにじみは切っています(`build.gd`)。

### オンラインで遊ぶ

- **ルームを作る人(ホスト):** 「オンライン」→「ルームを作成」。空島の左上に出る **パスワード(6文字)** をみんなに教えます。
- **ルームに入る人:** 「オンライン」→「ルームに参加」→ パスワードを入れて「ルームに入る」。
- 離れた場所どうしでも、インターネットにつながっていれば遊べます(ポート開放はいりません)。
- しくみ: ゲームの通信は **WebRTC**(ブラウザでもパソコンでも使える、直接つながる通信)です。つながる前の「住所の受け渡し」だけ、無料で公開されている伝言板サーバー(MQTT ブローカー `broker.hivemq.com`)を使います。くわしくは `scripts/room.gd` のメモを見てください。
- 学校や会社など、ネットワークの設定によってはつながらないことがあります(直接つながる通信が止められている場合)。
- Windows のファイアウォールの確認が出たら「許可」を選んでください。

## ファイルの説明(はじめての人向け)

```
freedom-land/
├─ project.godot        … プロジェクトの設定(名前・画面の大きさなど)
├─ scenes/main.tscn     … 最初に開く画面。main.gd がついているだけ
├─ fonts/               … 日本語フォント(ブラウザ版にはパソコンのフォントがないので同梱)
├─ docs/                … ブラウザ版(書き出したもの。GitHub Pages で公開)
├─ addons/webrtc_native/ … パソコン版で WebRTC を使うための公式拡張(godotengine/webrtc-native)
└─ scripts/
   ├─ main.gd           … 司令塔。タイトル画面、操作の登録、画面の切りかえ
   ├─ net.gd            … ネットワーク係。ルームを作る・入る・プレイヤー一覧
   ├─ room.gd           … ルームとパスワードの係。伝言板(MQTT)で WebRTC の接続を始める
   ├─ build.gd          … ものづくり係。床・木・文字などを作る便利な関数
   ├─ player.gd         … キャラクター。歩く・ジャンプ・ダッシュ・通信
   ├─ base_game.gd      … すべてのゲームの土台。カメラ・時間・点数・結果発表
   ├─ hub.gd            … 広場
   ├─ pause_menu.gd     … ポーズメニュー
   ├─ touch_controls.gd … スマホ用の画面ボタン(スティック・ジャンプ・ダッシュ・ポーズ)
   └─ games/
      ├─ coin_rush.gd       … コインラッシュ
      ├─ bump_ring.gd       … ぶつかりリング
      ├─ panel_drop.gd      … ぬけおちパネル
      ├─ spin_bar.gd        … ぐるぐるバー
      └─ lane_battle.gd     … Bond(チーム5対5のレーンバトル)
```

どのファイルにも、何をしているかを日本語のメモ(`#` や `##` で始まる行)で書いています。
3Dの見た目は画像やモデルのファイルを使わず、四角・円柱・球などの形を組み合わせてプログラムで作っています。

### 新しいゲームを足すには

1. `scripts/games/` に新しいファイルを作り、1行目を `extends "res://scripts/base_game.gd"` にする
2. `build_world()`(ステージ)、`spawn_point()`(スタート位置)、`game_process()`(毎フレームの処理)を書く
3. `main.gd` の `SCENES` と `GAMES` に1行ずつ足す(空島のポータルが自動で増えます)

## 開発用のテスト

```bash
godot --headless --path . -- --autotest
```

すべての画面を順番に開いて、エラーが出ないか確かめます。`--autohost` と `--autojoin` を2つ同時に起動すると、通信のテストもできます(ホストがパスワードを `user://autotest_room.txt` に書き、ゲストがそれを読んで入ります。インターネットが必要です)。
`-- --lanetest` で Bond をCPUだけで早送りで戦わせ、得点が入るか確かめられます。`-- --touch` をつけると、タッチ画面でなくてもスマホ用ボタンを表示します。
